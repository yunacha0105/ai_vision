- 실험 대상: 1일차에서 확보한 병뚜껑 ROI 및 2일차 Challenge의 밝은 병뚜껑 이미지
- 사용 방법: BGR/Gray/HSV, Brightness, Gamma, CLAHE, Noise Filter, Sharpening, Threshold/Otsu
- 추가 Challenge 비교: CLAHE 1.0/2.0/3.0, Gamma 1.2/1.5, Gaussian 5×5
- 최종 코드 상태: `src/17_day02_challenge.py`의 `result = image.copy()` — **전처리 미사용**

## 1. 실험 목적 및 데이터

1일차에는 병뚜껑의 검사 영역인 ROI를 정했다. 2일차에는 해당 ROI가 밝기 부족, 낮은 대비, Noise, Blur 등의 조건에서 어떻게 달라지는지 확인하고, 전처리 방법과 파라미터를 비교했다. 특히 마지막 Challenge에서는 밝은 병뚜껑과 회색 배경이 비슷한 명도를 가져 Otsu 이진화만으로 분리가 어려운 사례를 분석하였다.

| 데이터 | 사용 목적 | 특이사항 |
|---|---|---|
| `cap_on_reference.jpg` / `cap_off_reference.jpg` | 정상·불량 기준 ROI | 1일차 Live ROI 결과 활용 |
| `dark.jpg` | 밝기·Gamma 비교 | 기준 ROI에서 인위적으로 어둡게 생성 |
| `low_contrast.jpg` | CLAHE·Threshold 비교 | 기준 ROI에서 인위적으로 저대비 생성 |

이번 기록에서는 별도의 Glare 촬영 결과를 사용하지 않았다.

## 2. 기본 실습별 관찰과 판단

### 2.1 Color Space

BGR은 원래의 색상 정보를, Gray는 밝기 정보를, HSV는 색상(H)·채도(S)·명도(V)를 분리해 나타낸다. 실제 기준 ROI는 어두운 병뚜껑과 밝은 배경의 차이가 주로 명도에 나타난다. 따라서 이번 유무 검사에서는 **Gray와 밝기 기반 분리**를 우선 검토했다. 다만 HSV의 H 채널은 무채색에 가까운 병뚜껑에서 주요 판별 정보로 보기 어려웠다.

### 2.2 Brightness — `alpha=1.0`, `beta=0/20/50/80`

`beta`가 커질수록 어둡게 만들어진 이미지의 뚜껑 표면이 밝아졌으며 경계의 시인성이 좋아졌다. 그러나 `beta=80`에서는 배경과 병의 밝은 부분까지 함께 밝아져 대비가 반드시 개선되는 것은 아니었다. 밝기 향상과 객체 분리는 별개의 목표임을 확인했다.

### 2.3 Gamma — `0.6/0.8/1.0/1.2/1.5/2.0`

실습 코드의 감마 정의에서는 1.0이 변환 없는 기준이고, 1보다 큰 값을 적용하면 어두운 영역이 밝아졌다. 0.6/0.8은 어두운 부분을 더 어둡게 했고, 1.5/2.0에서는 어두운 뚜껑의 표면과 홈이 더 보였다. 다만 배경도 함께 변하므로 검사 성능 향상은 Otsu 결과로 확인해야 한다.

### 2.4 CLAHE — `clipLimit=1.0/2.0/3.0/4.0`, `tileGridSize=(8,8)`

저대비 ROI에서는 CLAHE 강도를 높일수록 병뚜껑의 세로 홈과 경계가 강조되었다. 하지만 4.0처럼 강한 적용에서는 배경 질감도 함께 두드러졌다. 특히 뒤의 Challenge에서는 강한 CLAHE가 이진화 Noise를 증폭시키는 결과를 보였으므로 강도를 높이는 것이 항상 유리하지 않다.

### 2.5 Noise Filter — Gaussian / Median / Bilateral

| 방법 | 조건 | 결과 관찰 |
|---|---|---|
| Gaussian | 3×3 | 일부 잡음을 부드럽게 줄이나 점 형태 Noise가 남음 |
| Gaussian | 7×7 | 더 부드러워지지만 병뚜껑 외곽선도 흐려짐 |
| Median | 3×3 | 밝고 어두운 점 Noise 감소와 외곽 보존의 균형이 비교적 좋음 |
| Median | 7×7 | 점 Noise를 강하게 줄이나 작은 세부 경계는 약해짐 |
| Bilateral | 코드의 비교 조건 | 경계를 보존하려는 특성이 있으나 독립적인 흰 점 Noise 일부가 남음 |

**판단:** Noise의 종류에 따라 적절한 Filter가 다르며, Noise가 크게 줄어들어도 중요한 객체 경계가 사라지면 검사에 불리하다.

### 2.6 Sharpening

Gaussian Blur 7×7로 일부러 흐리게 만든 이미지에 Sharpening Kernel을 적용했다. 흐려진 경계가 일부 강조되었지만 기준 원본 영상의 선명도가 완전히 복원되지는 않았다. 촬영 단계에서 손실된 정보는 Sharpening만으로 복원하기 어렵다.

### 2.7 Threshold 및 Otsu — 저대비 기준 이미지

| 방식 | 관찰 결과 |
|---|---|
| Threshold 80 | 대부분 검게 나와 검사 대상 구분에 불리 |
| Threshold 120 | 어두운 병뚜껑이 흰색 객체로 비교적 잘 분리됨 (`BINARY_INV`) |
| Threshold 160 | 지나치게 많은 영역이 흰색으로 바뀜 |
| Otsu | 임계값을 자동 결정하여 수동 값과 비교할 수 있음 |

저대비 예제에서 Original+Otsu, Gaussian+Otsu, CLAHE+Otsu를 비교한 결과, 전처리를 적용했다고 객체 분리가 반드시 좋아지는 것은 아니었다. Gaussian은 경계를 부드럽게 했고 CLAHE는 세부와 일부 불필요한 무늬도 강조했다.

## 3. Mini Challenge — 문제 정의와 ROI

`challenge.jpg`는 어두운/낮은 대비 조건으로 촬영한 **밝은 병뚜껑**이다. 주변 배경과 병뚜껑의 명도 차이가 충분하지 않으며, 병뚜껑 아래 결합부의 어두운 틈은 상대적으로 잘 보인다. 원본 전체 이미지에서 병뚜껑 주변을 ROI로 추출했으며, 원본은 `roi_temp/challenge_original.jpg`로 별도 보존했다.

이번 Challenge에서는 밝은 병뚜껑을 **흰색 객체**로 보기 위해 `THRESH_BINARY + THRESH_OTSU`를 사용했다. 이 설정은 기본 예제의 어두운 뚜껑에 적용했던 `THRESH_BINARY_INV`와 구분한다.

## 4. Mini Challenge — 시도한 방법과 파라미터

| 방법 | 파라미터 | 전처리 영상 관찰 | Otsu 결과 및 한계 |
|---|---|---|---|
| 전처리 없음 | 원본 Gray + Otsu | 밝은 병뚜껑과 회색 배경의 구분이 약함 | 밝은 배경까지 흰색으로 분류됨 |
| CLAHE | clipLimit 1.0, tile 8×8 | 지역 대비 소폭 증가 | 결합부의 검은 선은 유지되나 배경까지 함께 흰색 |
| CLAHE | clipLimit 2.0, tile 8×8 | 홈·표면 질감과 잡음이 더 두드러짐 | 배경/객체 분리 문제는 해결되지 않음 |
| CLAHE | clipLimit 3.0, tile 8×8 | 질감·Noise 과도하게 강조 | 뚜껑 표면과 배경에 검은 점이 크게 늘어남 — 실패 사례 |
| Gamma | 1.2 | 전반적으로 밝아짐 | 원본 Otsu와 거의 유사 |
| Gamma | 1.5 | 1.2보다 밝아짐 | 객체뿐 아니라 배경도 밝아져 분리 개선 미미 |
| Gaussian | 5×5 | 세부 잡음과 경계가 부드러워짐 | 일부 작은 잡음 감소, 객체/배경 분리는 여전히 어려움 |

### 4.1 Otsu 결과의 정량적 참고값

공유된 이진화 이미지(크기 920×789)에서 픽셀값 128 이상을 흰색으로 보고 비율을 계산했다. 아래 값은 **이진화 결과의 구성 비율**이지 검출 정확도, IoU 또는 성능 개선률이 아니다. 원본과 다른 픽셀 비율 역시 단순 변화량이며, 크게 달라졌다는 이유만으로 더 좋은 결과가 아니다.

| 처리 | 흰색 픽셀 비율 | 원본 이진화와 달라진 픽셀 비율 |
|---|---:|---:|
| 원본 Otsu | 84.4% | 0.0% |
| CLAHE 1.0 + Otsu | 89.7% | 5.5% |
| CLAHE 2.0 + Otsu | 89.5% | 6.0% |
| CLAHE 3.0 + Otsu | 56.2% | 31.2% |
| Gamma 1.2 + Otsu | 85.2% | 0.8% |
| Gamma 1.5 + Otsu | 87.3% | 2.9% |
| Gaussian 5×5 + Otsu | 84.5% | 0.9% |

**해석:** CLAHE 3.0은 원본과 가장 많이 달랐으나 검은 Noise 영역이 증가했기 때문에 개선으로 보지 않았다. Gamma와 Gaussian은 원본에 비해 결과 변화가 작았다. 모든 방법에서 밝은 병뚜껑과 밝은 배경을 온전히 별도의 영역으로 분리하는 데 한계가 있었다.

## 5. 전처리 선택 및 이유

**최종 선택: 전처리 미사용 (`result = image.copy()`).**

1. CLAHE의 강도를 높이면 홈은 보이지만 배경 Texture도 강조돼 Otsu 후 잡음이 증가했다.
2. Gamma는 밝기 자체를 조정했지만, 밝은 객체와 밝은 배경 사이의 상대적인 구분을 충분히 개선하지 못했다.
3. Gaussian 5×5는 작은 잡음에 유용할 가능성을 보였으나 객체와 배경을 구별하는 핵심 문제를 해결하지 못했다.
4. 불필요한 전처리를 적용하지 않고 원본 상태를 유지한 뒤 후속 방법을 검토하는 것이 이 실습의 목적에 부합한다.

최신 GitHub 커밋 `f421acb`의 `src/17_day02_challenge.py`에 `result = image.copy()`가 반영되어 있으며, 저장된 `challenge_original_otsu.jpg`와 `challenge_result_otsu.jpg`는 동일한 바이너리 결과이다. 이는 **전처리 미사용 판단의 일관성 확인**이지, 이진화가 성공했다는 뜻은 아니다.

| Otsu 결과 | 병뚜껑 표면에 넓은 검은 영역과 점 잡음이 나타나 연속적인 객체 마스크가 훼손됨 |

## 7. 한계 및 3일차 확인 사항

- 단일 Otsu 임계값은 명도 분포가 겹치는 밝은 객체와 배경을 구분하지 못할 수 있다.
- 밝은 배경과 뚜껑의 분리는 촬영 배경/조명 개선이나 다른 특징의 도입이 필요할 수 있다.
- Gaussian 5×5의 잡음 억제 효과는 3일차 Morphology·Contour 평가와 함께 재검토할 수 있다.
- 2일차에서는 정량적인 자동 OK/NG 검출 성능을 측정하지 않았다. 성공률·정확도는 제시하지 않는다.

## 8. 최종 결론

기본 실습을 통해 Brightness, Gamma, CLAHE, 각종 Filter, Sharpening 및 Otsu가 영상에 미치는 영향을 비교하였다. 추가 Mini Challenge에서는 CLAHE 3조건, Gamma 2조건, Gaussian 1조건을 실제 결과로 비교했고, 모두 객체와 배경의 분리를 충분히 개선하지 못한다고 판단해 **전처리 미사용**을 선택했다. 이후 Rule 기반 검사에서는 이 판단을 기준으로 형태·면적 측정이나 촬영조건 개선 가능성을 확인한다.


# Day 08 — Cut-Paste Synthetic Defect 개선 실험

## 1. 실험 목적

8일차 Mini Challenge에서는 MVTec AD bottle의 `contamination` 결함을 정상 이미지에 Cut-Paste 방식으로 합성했다.

5장의 이미지를 생성하는 데 성공했지만, 대부분의 이미지에서 갈색 원형 결함이 지나치게 크고 주변 이미지와 자연스럽게 연결되지 않는 문제가 나타났다.

특히 일부 결함은 병 내부 경계와 겹쳐 실제 오염보다 별도의 물체를 붙여 놓은 것처럼 보였다.

따라서 합성 이미지의 시각적 품질을 개선하기 위해 결함 크기, 합성 위치, 경계 블렌딩을 변경하고 Baseline과 비교했다.

## 2. Baseline과 개선 조건

기존 Challenge 2에서 생성한 5장을 Baseline으로 사용했다.

추가 개선에서는 Baseline Metadata에 기록된 정상 이미지, 결함 원본, 회전 각도 등을 재사용하고, 결함 크기와 위치, 경계 처리 조건을 변경했다.

| 항목 | Baseline | Improvement |
|---|---|---|
| Defect Type | contamination | contamination |
| 생성 이미지 수 | 5장 | 5장 |
| 결함 크기 | Scale 0.6~1.0 | Baseline Scale의 40% |
| 합성 위치 | 기존 무작위 배치 | 기존 중심을 기준으로 중앙 영역 제한 |
| 경계 블렌딩 | Gaussian 3×3 | Gaussian 9×9 |
| 결함 원본 | 기존 이미지·Mask | 동일한 원본 사용 |

개선 이미지는 기존 결과를 덮어쓰지 않고 별도 폴더에 저장했다.

이번 실험은 여러 조건을 동시에 변경한 탐색적 실험이다. 따라서 결과가 좋아지더라도 특정 조건 하나의 효과로 해석할 수는 없다.

## 3. 개선 방법

### 3-1. 결함 크기 축소

기존 결함은 병 내부의 넓은 면적을 차지해 부자연스러웠다.

이를 줄이기 위해 기존 합성 Scale에 0.4를 곱해 결함 Patch의 크기를 축소했다.

크기 조정 후에도 결함 원본과 Mask가 서로 맞도록 동일한 크기 변환을 적용했다.

### 3-2. 합성 위치 제한

기존에는 결함이 병 내부 경계와 겹치는 경우가 있었다.

개선에서는 Baseline의 합성 중심 위치를 참고하되, 이미지의 중앙 영역에 가깝도록 위치를 제한했다.

- X 중심: 이미지 너비의 35~65%
- Y 중심: 이미지 높이의 25~75%

이 방식은 병의 정확한 내부 Mask를 사용하는 것은 아니므로, 모든 합성 위치가 적절하다고 보장하지는 않는다.

### 3-3. 경계 블렌딩 강화

기존에는 결함 Mask를 3×3 Gaussian Blur로 부드럽게 처리했다.

개선에서는 9×9 Gaussian Blur를 사용해 합성 경계를 더 넓게 혼합했다.

다만 경계 Blur를 강화하더라도 결함 자체의 형태가 원형인 문제는 그대로 남을 수 있다.

## 4. 개선 결과

Baseline과 Improvement 이미지를 나란히 비교해 총 5장의 시각적 품질을 확인했다.

| 이미지 | Baseline 문제 | Improvement 결과 |
|---|---|---|
| synthetic_000.png | 큰 결함이 병 내부 상단을 가림 | 결함 크기가 줄고 내부에 위치함 |
| synthetic_001.png | 큰 원형 결함이 눈에 띔 | 결함 크기가 감소했지만 원형 경계는 남음 |
| synthetic_002.png | 병 내부 하단에 큰 결함이 나타남 | 크기가 줄고 병 내부 중앙에 가까워짐 |
| synthetic_003.png | 결함이 병 내부 경계와 크게 겹침 | 크기와 겹침 정도가 감소함 |
| synthetic_004.png | 내부에 원형 구조와 경계가 나타남 | 원형 구조가 축소됐지만 합성 흔적은 남음 |

전체적으로 결함이 차지하는 면적이 감소했고, 기존보다 병 내부의 배경을 덜 가리게 됐다.

특히 `synthetic_003.png`에서는 Baseline에서 나타난 결함의 과도한 크기와 경계 겹침 문제가 줄었다.

하지만 개선 이미지에서도 원형 결함이 뚜렷하게 남아 있었다. 일부 이미지는 여전히 실제 오염보다 원형 물체를 붙여 놓은 것처럼 보였다.

## 5. 개선 결과 분석

이번 실험에서 가장 분명하게 확인한 변화는 결함 크기의 감소다.

Baseline에 비해 결함이 이미지에서 차지하는 비율이 작아져 과도하게 눈에 띄는 문제가 완화됐다.

합성 위치도 일부 이미지에서 더 적절해졌지만, 정확한 병 내부 Mask를 사용한 것은 아니므로 위치 제한의 효과에는 한계가 있었다.

경계 블렌딩을 강화했지만 원형 구조가 사라지지는 않았다. 따라서 이번 결과만으로 경계 처리가 충분히 개선됐다고 판단하기는 어렵다.

또한 크기, 위치, Blur를 동시에 변경했기 때문에 각 방법의 개별 효과는 확인하지 못했다.

## 6. 남아 있는 문제와 추가 개선 방향

이번 결과에서 가장 크게 남은 문제는 결함 Patch 자체의 형태다.

크기를 줄여도 갈색 원형 구조가 그대로 축소되어 실제 오염처럼 보이지 않는 경우가 있었다.

추가 개선을 진행한다면 다음 항목을 검토할 수 있다.

1. 실제 결함 Mask의 형태를 확인하고, 불필요하게 넓은 영역이 포함됐는지 점검
2. 병 내부 유효 영역 Mask를 적용해 합성 위치 제한
3. 결함의 색상·질감과 합성 경계가 주변 이미지와 자연스럽게 연결되는지 비교
4. 한 번에 하나의 조건만 변경하여 개선 효과 분리

특히 원본 Ground Truth Mask가 실제 오염을 정확히 나타내는지 확인하는 작업이 우선 필요하다.

## 7. 정리

이번 Improvement 실험에서는 기존 Contamination Cut-Paste 이미지 5장의 과도한 결함 크기를 줄이고, 합성 위치와 경계 처리를 변경했다.

그 결과 시각적으로 큰 원형 결함이 차지하는 면적과 일부 위치 겹침 문제가 완화됐다.

그러나 결함 자체가 원형에 가까운 문제는 해결하지 못했고, 실제 오염 이미지와 충분히 유사하다고 판단하기는 어려웠다.

또한 이번 실험은 합성 이미지의 시각적 품질을 비교한 것으로, 합성 데이터를 이용한 모델 학습이나 Accuracy·Recall 개선 여부는 검증하지 않았다.

따라서 이번 결과는 합성 이미지 품질의 일부 개선으로 기록하고, 실제 검사 성능 향상으로 해석하지 않는다.
